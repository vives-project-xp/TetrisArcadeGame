# Documentation

This folder contains the main project documentation for the Tetris Arcade Game. It brings together the hardware diagrams, Raspberry Pi startup configuration, bill of materials, and project posters.

## Contents
- [Architecture](./Architecture/README.md): electrical diagram, LED diagram, and UML-related documentation
- [Autostart](./Autostart/Autostartscript.md): Raspberry Pi autostart setup and the `tetris.service` configuration
- [BOM-list](./BOM-list/README.md): bill of materials with the parts needed for the project
- [Posters](./Posters): project posters and presentation material

Use this folder as the starting point for the non-code documentation of the project.
