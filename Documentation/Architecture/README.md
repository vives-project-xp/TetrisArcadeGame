# Architecture

This folder contains the diagrams that explain both the hardware wiring and the system structure of the Tetris arcade.

## Hardware Diagrams

The electrical diagram and the LED diagram belong together. The electrical diagram shows how the electronics are connected, while the LED diagram explains how the LED matrix is arranged so the software can map the in-game grid to the physical display.
