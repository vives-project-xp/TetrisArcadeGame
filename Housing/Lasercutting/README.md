# Lasercutting

This folder contains all the parts needed for laser cutting the different sections.

## Parts

- [Back Plate](./Backplate) : Here you can find the file for laser cutting the backplate.
- [Console](./Console) : Here you can find the file for laser cutting the console.
- [Next Block](./NextBlok) : Here you can find the filse for laser cutting the Next Block Field.
- [Playing Field](./PlayingField) : Here you can find the files for laser cutting the Playing Field.
